# 对三个数据集进行说明

三个数据集都属于 *biomedical NER* 数据集

| 数据集   | 主要领域         | 核心实体                   | 适合测试      |
| ----- | ------------ | ---------------------- | --------- |
| bc2gm1 | 分子生物学 / 基因组学 | `GENE`                 | 基因、蛋白名称识别 |
| 数据集 2 | 临床医学 / 药理学   | `CHEMICAL` + `DISEASE` | 药物、疾病联合识别 |
| 数据集 3 | 遗传病 / 医学遗传学  | `DISEASE`              | 疾病名称识别    |
